# Documentación PlayPredict

Índice de la documentación conceptual y de producto del proyecto. El código y su estado real de implementación viven en `CLAUDE.md`, `SESSION.md`, `PROJECT_STATUS.md` y `PLAN_DE_TRABAJO.md` (raíz del repositorio) — estos documentos describen el diseño y la visión, no necesariamente lo ya implementado.

- [REGLAS_NEGOCIO_v1.0.md](arquitectura/REGLAS_NEGOCIO_v1.0.md) — reglas funcionales del MVP.

- [TIPOS_PRONOSTICOS_v1.0.md](arquitectura/TIPOS_PRONOSTICOS_v1.0.md) — clasificación de los tipos de pronóstico que PlayPredict podrá ofrecer.
- [MOTOR_PUNTUACION_v1.0.md](arquitectura/MOTOR_PUNTUACION_v1.0.md) — funcionamiento conceptual del Motor de Puntuación (transformar un pronóstico en puntos).
